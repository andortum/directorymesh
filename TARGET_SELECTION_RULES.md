# Target Selection Rules

## Tier-1 eligibility
A target can be Tier-1 only if:
1. It has explicit permission for relevant product/project announcements or listings.
2. Ownership/workflow is legitimate and documented.
3. Automation can run without bypassing anti-bot protections.
4. Rate limits and community norms can be respected by default.

## Exclusion rules
Exclude targets that:
- Prohibit automated submissions in their terms.
- Depend on evasion or deceptive identity behavior.
- Have ambiguous ownership claim flows.

## Community targeting rules
For `COMMUNITY_ENGAGEMENT_SURFACE`:
- Must support meaningful project discussion/showcase/launch content.
- Must include per-community posting policy summary.
- Must enforce default cooldown: max 1 action/24h/community.
